# Assets Folder

This folder contains images and media assets for the project.

## Required Images

### banner.png
- **Purpose:** Main banner for README
- **Size:** 1200x400 pixels recommended
- **Format:** PNG with transparency or solid background
- **Content:** Project logo/title with tagline

Suggested design elements:
- Selenium logo (green) → Arrow → Playwright logo (orange)
- Title: "Selenium2Playwright"
- Subtitle: "Convert Selenium to Playwright with Local LLM"

### cli-demo.png
- **Purpose:** Screenshot of CLI in action
- **Size:** 800x400 pixels
- **Format:** PNG
- **Content:** Terminal showing conversion process

### conversion-example.png
- **Purpose:** Side-by-side comparison
- **Size:** 1200x600 pixels
- **Format:** PNG
- **Content:** Before/After code comparison

## Creating Images

You can create these images using:

1. **Canva** (canva.com) - Free design tool
2. **Figma** (figma.com) - Professional design
3. **Carbon** (carbon.now.sh) - Code screenshots
4. **GitHub Social Preview** - Built-in tool

## Color Scheme

- Primary: `#2E8555` (Selenium Green)
- Secondary: `#D63384` (Playwright Pink/Orange)
- Accent: `#45BA4B` (Success Green)
- Background: `#1a1a2e` (Dark)
- Text: `#ffffff` (White)

## Logo Ideas

1. **Converter Arrow:** Selenium icon → Arrow → Playwright icon
2. **Code Transform:** `{ }` with arrows indicating transformation
3. **Robot/AI Theme:** Robot converting code with local LLM chip
